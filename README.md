🔹 ChatX – AI-Powered Client Onboarding Assistant 💬
A full-stack SaaS solution that simplifies client onboarding with AI chat integration and secure user management.

Features:

Developed with Java (Spring Boot) and PostgreSQL using a modular architecture (Controller-Service-Repository).

Secure multi-user access with JWT Authentication and Spring Security.

Responsive React.js frontend for smooth client interactions.

Reduced onboarding time by ~70% through AI-driven workflows.

Dockerized and built with future plans for multi-tenant SaaS scalability.

Tech Stack: Java, Spring Boot, Spring Security, PostgreSQL, React.js, Docker, REST APIs, JWT
